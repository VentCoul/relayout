## Передумови

| Що | Навіщо | Де взяти |
| :---- | :---- | :---- |
| Rust (stable) | Уся логіка | [rustup.rs](https://rustup.rs) |
| Node.js і pnpm | Tauri CLI | [nodejs.org](https://nodejs.org), `npm install -g pnpm` |
| macOS: Xcode Command Line Tools | Компілятор, фреймворки | `xcode-select --install` |
| Windows: Microsoft C++ Build Tools, WebView2 | Компілятор; рушій вікна налаштувань (у Windows 11 уже є) | [visualstudio.microsoft.com](https://visualstudio.microsoft.com/visual-cpp-build-tools/), компонент «Desktop development with C++» |
| Linux: WebKitGTK 4.1, libayatana-appindicator, librsvg, libxdo | Вікно налаштувань, трей | Пакетний менеджер; див. `build-linux.sh` |

Збирати треба на тій ОС, для якої потрібна збірка.

## Запуск і збірка

```sh
pnpm install     # Tauri CLI
pnpm test        # тести ядра
pnpm dev         # запуск у режимі розробки
pnpm build       # інсталятори для поточної ОС у target/release/bundle/
```

На Windows і Linux є скрипти, які перевіряють і (за згодою) встановлюють інструменти, а потім збирають інсталятор:

| Скрипт | Що робить |
| :---- | :---- |
| `build-windows.bat` | Встановлює Rust, Node.js і C++ Build Tools через `winget`, збирає NSIS-інсталятор у `target\release\bundle\nsis`. `build-windows.bat dev` — режим розробки. |
| `./build-linux.sh` | Встановлює системні бібліотеки (`apt`, `dnf` або `pacman`) і Rust, збирає `.deb`, `.rpm` (якщо є `rpmbuild`) та AppImage. `./build-linux.sh dev` — режим розробки. `RELAYOUT_YES=1` — встановлювати без запитань. |

### macOS: дозвіл після кожної збірки

Збірка підписується одноразовим (ad-hoc) підписом, який змінюється з кожною збіркою. macOS прив'язує дозвіл «Універсальний доступ» до підпису, тож після перезбірки перемикач у списку горить, але не діє. Прибрати старий запис:

```sh
tccutil reset Accessibility dev.relayout.desktop
```

Або в Системні параметри → Приватність і безпека → Універсальний доступ виділити Relayout і натиснути **−**. Постійно розв'язує це лише підпис стабільним сертифікатом (власним для розробки або Apple Developer ID для розповсюдження).

## Структура проєкту

```
crates/core/              ядро: без залежностей і без вводу-виводу
  src/lib.rs              визначення напрямку, конвертація, Caps Lock, оцінка «природності» тексту
  src/layouts.rs          таблиці розкладок
  src/bigrams.rs          статистика пар літер (згенерована)
src-tauri/                програма Tauri
  src/main.rs             запуск, трей, гаряча клавіша, команди для вікна налаштувань, --convert
  src/engine.rs           сценарій після натискання гарячої клавіші
  src/platform/           усе, що залежить від ОС
    macos.rs | windows.rs | linux.rs | unsupported.rs
  capabilities/           права вікна налаштувань (порожні: лише власні команди)
  tauri.conf.json         конфігурація Tauri, CSP, інсталятори
ui/                       вікно налаштувань: index.html, main.js, style.css
tools/                    генерація статистики пар літер
assets/                   вихідні іконки та скрипт, що їх малює
build-windows.bat, build-linux.sh
```

## Як працює виправлення

Сценарій у `src-tauri/src/engine.rs`. Одночасно виконується не більше одного виправлення.

1. Отримати поточну розкладку й таблиці розкладок користувача (`platform::current_lang`, `platform::tables`).
2. Запам'ятати вміст буфера обміну (текст або зображення) й очистити буфер.
3. Дочекатися, поки користувач відпустить модифікатори гарячої клавіші (Windows, Linux), і надіслати `Ctrl+C` / `⌘C`.
4. Якщо за 300 мс у буфері нічого не з'явилось, виділити попереднє слово (`Ctrl+Shift+←` / `⌥⇧←`) і скопіювати ще раз.
5. Виправити текст у ядрі (`relayout_core::convert`).
6. Покласти результат у буфер з позначкою «прихований» і надіслати `Ctrl+V` / `⌘V`.
7. Повернути попередній вміст буфера, затерти обидва тексти в пам'яті (`zeroize`).
8. Вимкнути Caps Lock, якщо виправлявся регістр, і перемкнути системну розкладку.

Логіка ядра (`crates/core/src/lib.rs`):

- **Caps Lock** розпізнається за «перевернутим» регістром: є слово на кшталт `пРИВІТ`, і ніде немає малих літер, крім першої літери слова. Слова розділяються лише пробілами, бо в чужій розкладці літера може потрапити на клавішу розділового знака (`k.LBYF` = `лЮДИНА`).
- **Напрямок розкладки** визначається тим, яких літер у тексті більше, латинських чи кириличних; за рівності вирішує поточна розкладка системи. Слова, які вже повністю в цільовому алфавіті, не змінюються.
- **Caps Lock + розкладка.** Обидва варіанти («лише регістр» і «регістр + розкладка») оцінюються функцією `naturalness` за статистикою пар літер. Розкладка міняється, лише якщо її варіант природніший щонайменше на `LAYOUT_MARGIN`. Так правильно набраний текст не псується, а в сумнівних випадках достатньо натиснути ще раз.
- **Типографські лапки** (`’`, `“` тощо), які редактори підставляють під час набору, конвертуються як клавіші `'` і `"`.

## Особливості платформ

| | macOS | Windows | Linux (X11) |
| :---- | :---- | :---- | :---- |
| Натискання | `CGEvent` з окремого джерела подій; модифікатори користувача не заважають | `SendInput`; спершу чекаємо, поки відпустять модифікатори (до 1,5 с) | XTest; так само чекаємо модифікатори |
| Таблиці розкладок | Вбудовані: `Ukrainian - PC` або `Ukrainian` (обирається за увімкненими) | Вбудовані: `Ukrainian (Enhanced)` або стара `Ukrainian` (розрізняються за клавішею `\`) | Читаються з розкладки X-сервера; підтримуються групи 1–2 |
| Перемикання розкладки | `TISSelectInputSource` | `WM_INPUTLANGCHANGEREQUEST` активному вікну | XKB lock group |
| Caps Lock | IOKit `IOHIDSetModifierLockState` | Натискання `VK_CAPITAL`, якщо увімкнено | XKB: зняти модифікатор Lock |
| Дозволи | «Універсальний доступ» | Не потрібні | Не потрібні |

Інші нюанси:

- **Linux, буфер обміну:** на X11 вміст буфера віддає програма, яка його встановила, поки вона жива. Тому `engine.rs` тримає один об'єкт буфера на весь час роботи програми.
- **Linux, Wayland:** глобальні гарячі клавіші та XTest не працюють для «рідних» Wayland-вікон. Обхід — `relayout --convert`, прив'язаний до гарячої клавіші в налаштуваннях системи (передається запущеному екземпляру через `tauri-plugin-single-instance`).
- **Linux, тестування в контейнері:** віртуальний X-сервер Xvfb ігнорує зміну розкладки (`setxkbmap`), тому для перевірки розкладок і їх перемикання використовуйте TigerVNC (`Xtigervnc`).

## Додавання мови

1. `crates/core/src/layouts.rs`: додати варіант у `Lang` і таблиці 47 клавіш для потрібних розкладок (порядок клавіш — як у наявних таблицях; `NO_CHAR` для клавіш без символу). Тест `tables_cover_the_same_keys` перевіряє розмір таблиць.
2. `crates/core/src/lib.rs`: навчити `is_letter_of` та `detect_source` розпізнавати алфавіт мови. Зараз логіка розрахована на пару «латиниця ↔ кирилиця»; для двох мов з одним алфавітом (наприклад, української й російської) напрямок доведеться визначати інакше.
3. `src-tauri/src/platform/*.rs`: розпізнавати ідентифікатори розкладок мови й повертати її таблиці.
4. Для Caps Lock + розкладки: додати мову в `tools/bigrams.py` і перегенерувати статистику.

## Статистика пар літер

`crates/core/src/bigrams.rs` згенеровано, вручну не редагується. Там лише кількості пар літер, без тексту корпусу.

```sh
python3 tools/extract_macos_corpus.py /tmp/corpus      # лише macOS: рядки інтерфейсу macOS англійською та українською
python3 tools/bigrams.py /tmp/corpus/en.txt /tmp/corpus/uk.txt > crates/core/src/bigrams.rs
```

Замість корпусу з macOS підійдуть будь-які великі тексти кожною мовою.

## Тести

```sh
pnpm test                      # cargo test -p relayout-core
```

Тести ядра покривають обидва напрямки конвертації, регістр і розділові знаки, українські літери (`ї`, `є`, `ґ`, апостроф), змішаний текст, Caps Lock (окремо й разом з розкладкою), типографські лапки, повний розмір таблиць розкладок.

Тести таблиць кириличних символів X11 лежать у `src-tauri/src/platform/linux.rs` і запускаються лише на Linux.

## Ручна перевірка

Перед випуском перевірити на кожній ОС:

- [ ] Іконка «Aя» з'являється в треї / рядку меню; «Налаштування…» відкриває вікно.
- [ ] `ghbdsn` без виділення + гаряча клавіша → `привіт`, розкладка перемкнулась на українську.
- [ ] `руддщ` → `hello`, розкладка перемкнулась на англійську.
- [ ] Виділене `Привіт, zr cghfdb&` → `Привіт, як справи?`.
- [ ] `]; 'lyscnm` → `їж єдність`; те саме в Outlook / Word / Notes з `’` замість `'`.
- [ ] Caps Lock: `пРИВІТ` → `Привіт`, Caps Lock вимкнувся; `gHBDSN` → `Привіт` одним натисканням.
- [ ] Повторне натискання повертає текст назад.
- [ ] Скопійоване до виправлення знову вставляється `Ctrl+V` / `⌘V` після нього.
- [ ] Зміна гарячої клавіші в налаштуваннях діє одразу й переживає перезапуск.
- [ ] «Запускати разом із системою» працює після перезавантаження.

## Випуск версії

1. Підняти версію в `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, `crates/core/Cargo.toml` і `package.json`.
2. Пройти [тести](#тести) і [ручну перевірку](#ручна-перевірка).
3. Закомітити й поставити тег: `git tag vX.Y.Z && git push --tags`.
4. Зібрати інсталятори на macOS (`pnpm build`), Windows (`build-windows.bat`) і Linux (`./build-linux.sh`).
5. Створити реліз на GitHub і прикріпити інсталятори: `gh release create vX.Y.Z <файли інсталяторів>`.

Відкат: встановити інсталятор попередньої версії або зібрати його з тегу (`git checkout vX.Y.Z`).
